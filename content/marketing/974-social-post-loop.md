Say **run the social loop** (or “next social post”) to build one owned post end to end. The loop runs only when asked. It does not post.

Each step is one skill, in this order. Write the pack under `content/marketing/` before the loop ends. Update the Demand Gen draft JSON to match. Do not skip a step because the last post already did it.

| Step | Skill | Job |
|------|--------|-----|
| 1 | Social Media Specialist | Name the slot from the cadence brief. Show-week only when a card is open. Otherwise always-on. Platforms: Instagram and Threads. X is deferred. Facebook is not a post. |
| 2 | Brand Systems Partner | Pick a layout from the template menu. Do not invent a frame. The image shows the readable path only (`setlistpickem.com/...`). Voice rules in that skill apply to the caption in step 3. |
| 3 | Social Demand Gen Operator | Write the caption to the brand skill. Two or three lines. Name Phish. Judge the job of this post: a new reader is being asked to make picks, so the last line is an invite in the present tense, not a miss and not a look back at a show they already played. Same words on each platform. Tracked URL in the caption only. `utm_medium=social`, `utm_campaign=seo_geo`, `utm_source` per platform. Persist the drafts. |
| 4 | Editor in Chief | Style and consistency against the brand skill. Do not write a second voice. Record pass or reject on the pack. Leave the queue in draft. |

After step 4 the pack is ready to paste. Queue `approve` and a live post happen only after the user accepts the pair. There is no publisher webhook.

## Pack

One post, one image, pasted twice (Instagram, then Threads). Not a carousel.

The note for that post records the slot, the layout, the image path, the Canva link, both captions, and a line from each step. First example: [`974-first-pack-how-it-works.md`](./974-first-pack-how-it-works.md).
